# WARPScoutGUI v2.5.4 — примечания к релизу

[English](RELEASE-2.5.4.en.md) | Русский

**Дата / Date:** 2026-10-11 · **Тип:** prerelease · **Ядро / core:** warpscout v0.16.0

Единый выпуск для всех шести платформ (политика выпуска: артефакты всех платформ под одним номером версии).

### Android (изменён)

- **🌓 Кнопка «Переключить тему» снова работает.** Кнопка в меню «Ещё» не имела атрибута `data-tab`, и делегированный обработчик кликов её не находил — нажатие молча терялось. Атрибут теперь ставится всегда, дополнительно на кнопку повешен прямой слушатель.
- **📂 Все кнопки «Открыть папку» отвечают мгновенно.** Любое нажатие показывает тост «Открываю папку: …» сразу, а итог — в каждой ветке: «Папка открыта» / «Выберите эту папку в открывшемся менеджере» / «Путь скопирован». Молчаливые отказы (`.catch(() => {})`) убраны из всего кода. На Android 11+ папка `Android/data/…` открывается сразу через системный SAF-выборщик — он видит её даже там, где обычные «Файлы» показывают пустоту (именно поэтому раньше казалось, что «кнопка ничего не делает»).
- **⬇️ Готовые конфиги — в Download/WARPScoutGUI.** Кнопка «Получить рабочий конфиг» на главной сохраняет файл в публичную папку `Download/WARPScoutGUI`: видна в любом файловом менеджере; Android 10+ — запись через MediaStore вообще без разрешений, Android 7–9 — с выданным правом записи; при недоступности — честное сообщение и сохранение в папку приложения. Диалог «Сохранить как…» открывается сразу в этой папке.
- **⏱ Живой индикатор скана на главной.** Пока идёт скан: пульсирующая точка, «Сканирую…», текущая фаза, таймер, шаги N/M и найденные узлы, кнопка «■ Остановить». Кнопка «Просканировать эндпоинты» на время скана превращается в «■ Остановить скан». После завершения — «● Скан завершён» и число живых эндпоинтов.
- **🧹 Убран технический путь до warpscout** (`…/libwarpscout.so` в nativeLibraryDir): само поле, «Папка warpscout.exe» и Windows-подсказка про «код -1» — пользователю там нечего делать.
- Файлы аккаунта/отчёты — как в 2.5.3: `Android/data/ru.warpscout.gui/files/WARPScoutGUI` (по умолчанию, без разрешений) или `/storage/emulated/0/WARPScoutGUI` (кнопка «🌐 В общую папку…»).

### Windows / Linux / macOS (изменений нет)

По политике выпуска пакеты пересобраны под единый номер 2.5.4 (`resources.neu`, `README.txt`); функциональных изменений нет.

### Обновление

- **Android:** ставится поверх 2.5.0–2.5.3 (тот же пакет, тот же ключ подписи; сертификат SHA-256 `67969ff2…ac9841`). Данные сохраняются.
- **Desktop:** распаковать zip поверх старой папки; аккаунт/отчёты/настройки не затрагиваются.
