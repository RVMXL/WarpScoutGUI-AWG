# GitHub Release notes — v2.5.7 (prerelease)

[English](RELEASE-2.5.7.en.md) | Русский

### WarpScoutGUI 2.5.7 — android-fix (пререлиз)

Точечный выпуск исправлений Android-версии. Политика выпуска не меняется:
каждый релиз содержит артефакты всех поддерживаемых платформ под единым
номером версии — включая платформы, код которых в данном выпуске не менялся.

**Изменения по платформам (2.5.7):**

| Платформа | Статус | Изменения в 2.5.7 |
|---|---|---|
| Android ARM64 | исправления | 1) Сохранение конфигов: «*.conf» больше не превращается в «*.conf.txt»/«*.txt» — MIME теперь выводится из расширения файла (платформенная таблица), для неизвестных системе расширений используется нейтральный MIME без канонического расширения; после вставки читается фактическое имя файла — UI показывает реальный путь. 2) «Открыть папку» запускает системные «Файлы» (DocumentsUI) по классу активности: OEM-проводники перехватывали ACTION_VIEW каталога и открывали свой корень, игнорируя папку из URI. 3) Запись через IS_PENDING убрана (малые одиночные записи): на ряде прошивок незавершённые записи отображались в Downloads как призрачные папки |
| Windows x86_64 | изменения функциональности отсутствуют | пересобран resources.neu (версионные бастеры ?v=25v9) |
| Linux x86_64 / ARM64 | изменения функциональности отсутствуют | пересобран resources.neu |
| macOS Apple Silicon / Intel | изменения функциональности отсутствуют | пересобран resources.neu |

**Служебное:** в LICENSE (Apache-2.0) заполнена строка копирайта —
`Copyright 2026 RVMXL` (исправление оформления, не отдельная версия).

**Обновление Android:** APK подписан тем же фиксированным ключом, что и
2.5.0–2.5.6 — обновление ставится поверх без удаления и потери данных
(versionCode 20507).
