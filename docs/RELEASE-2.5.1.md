# GitHub Release notes — v2.5.1 (prerelease)

[English](RELEASE-2.5.1.en.md) | Русский

### WarpScoutGUI 2.5.1 — правка Android (пререлиз)

Точечный выпуск: исправлена первая ошибка, найденная на **реальном Android-устройстве** в выпуске 2.5.0.

**Политика выпуска.** Каждый релиз содержит артефакты всех поддерживаемых платформ под единым номером версии — включая платформы, код которых в данном выпуске не менялся. В примечаниях для каждой платформы указывается, что именно изменено либо явно зафиксировано отсутствие изменений.

**Изменения по платформам (2.5.1):**

| Платформа | Статус | Изменения в 2.5.1 |
|---|---|---|
| Android ARM64 | **исправление** | FIX старта: WebView загружал `file:///android_asset/www/index.html`, тогда как `aapt2 -A` размещает содержимое `www/` в **корне** assets (`assets/index.html`) — при запуске возникала ошибка `net::ERR_FILE_NOT_FOUND`. Путь загрузки исправлен на `file:///android_asset/index.html`. Дополнительно: `versionCode` теперь синхронизируется из конфигурации при каждой сборке (обнаружено, что `aapt2 link --version-code` не перебивает явно заданный в манифесте `android:versionCode` — иначе 2.5.1 несла бы 20500 вместо 20501). **versionCode 20501** — обновление поверх 2.5.0 работает без потери данных |
| Windows x86_64 | изменения функциональности отсутствуют | пересобран под единый номер версии (resources.neu — 2.5.1, README.txt); поведение идентично 2.5.0 |
| Linux x86_64 | изменения функциональности отсутствуют | пересобран под единый номер версии |
| Linux ARM64 | изменения функциональности отсутствуют | пересобран под единый номер версии |
| macOS arm64 | изменения функциональности отсутствуют | пересобран под единый номер версии |
| macOS x64 | изменения функциональности отсутствуют | пересобран под единый номер версии |

**Обновление Android:** установите `WARPScoutGUI-2.5.1-android-arm64.apk` поверх установленной 2.5.0 — пакет и ключ подписи прежние (SHA-256 сертификата `67969FF2…AC9841`), версия кода выросла 20500 → 20501, данные приложения сохраняются.

**Состав пакетов:** как в 2.5.0 — resources.neu, bin/warpscout v0.16.0 (MIT) и папка licenses/ во всех desktop-архивах.
