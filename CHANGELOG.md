# Changelog

Все заметные изменения WARPScoutGUI-AWG фиксируются здесь; порядок — обратный хронологический, дата версии = дата релизного коммита в git.

Политика выпуска (с 2.5.0): каждый релиз содержит артефакты всех поддерживаемых платформ под единым номером версии — с указанием, что изменено на каждой платформе, либо с явной фиксацией отсутствия изменений; все выпуски 2.5.x публикуются на GitHub со статусом prerelease (блок «Политика выпуска» — `desktop-app/RELEASE-2.5.0.md`; развёрнутые примечания релизов — `desktop-app/RELEASE-2.5.0.md`, `RELEASE-2.5.8.md`, `RELEASE-2.5.9.md`).

## [2.5.9] — 2026-10-12

Security-харденинг по итогам внешнего техаудита (закрыты SEC-1/2/3/8, REL-1, частично ARCH-2).

- Все платформы (общий `resources.neu`): Content-Security-Policy в index.html — скрипты/стили/картинки только из локальных ресурсов приложения, соединения только к локальному API Neutralino; object-src/base-uri/form-action закрыты (SEC-3).
- Android: `allowBackup=false` — приватные ключи WARP не уходят в облачные резервные копии и adb backup (SEC-2); chmod в мосте принимает ровно форму «+x» для warpscout либо путей внутри guard-корней, числовые режимы и чужие цели отклоняются (SEC-1).
- Инструментарий: релизный публикатор параметризован — `scripts/release.sh` без путей песочницы (SEC-8); README.txt в пакетах показывает актуальный статус выпуска вместо устаревшего «2.5.1» (REL-1); версия в сайдбаре синхронизируется из `NL_APPVERSION` (частично ARCH-2).

## [2.5.8] — 2026-10-12

Android-фиксы по отчёту пользователя (на 2.5.7): перенос данных и запуск warpscout.

- Android: «В общую папку» действительно переносит аккаунт и отчёты — `migrateData()` склеивала пути Windows-разделителем `\` (получался файл с `\` в имени, чтение старого аккаунта падало молча); все склейки переведены на платформенный `pxJoin()` (на Windows поведение прежнее).
- Android: запуск warpscout восстановлен — `guardPath` получил режим «только чтение» для `nativeLibraryDir` (запись осталась под строгим guard).
- Android: при первом запуске 2.5.8 сама переносит застрявшие в app-specific папках аккаунт/отчёты (идемпотентно, без перезаписи).
- Windows/Linux/macOS: без изменений функциональности (пересборка ресурсов).

## [2.5.7] — 2026-10-12

Android-фиксы: имена конфигов и «Открыть папку».

- Android: сохранённые конфиги больше не получают двойное расширение (`*.conf` превращалось в `*.conf.txt`/`*.txt`): MIME для MediaStore/SAF выводится из расширения файла, для неизвестных расширений — кастомный MIME без расширения; `IS_PENDING` убран, реальное `DISPLAY_NAME` читается обратно и возвращается в UI.
- Android: «Открыть папку» запускает системный «Файлы» (DocumentsUI) явно по имени класса — OEM-проводники перехватывали ACTION_VIEW на каталог и открывали собственный корень, игнорируя URI папки.
- Windows/Linux/macOS: без изменений функциональности.

## [2.5.6] — 2026-10-12

Android: найдена первопричина неработающей кнопки «Открыть папку».

- Android: шесть методов моста (openPath, requestPublicAccess, pubDir, pubMirror, saveToDownloads, clipboardWrite) были объявлены в MainActivity вместо внутреннего класса Bridge, который WebView экспортирует в JS, — каждый вызов падал с «B.openPath is not a function» (в 2.5.3 молча, в 2.5.4/2.5.5 тостом); все шесть перенесены в Bridge без изменений, логика буфера обмена вынесена в `MainActivity.setClipboard`.
- Windows/Linux/macOS: без изменений функциональности.

## [2.5.5] — 2026-10-11

Security: закрыты все 19 CodeQL-алертов Android-моста.

- Android: команды GUI исполняются через ProcessBuilder напрямую (POSIX-токенизация argv вместо `sh -c` — метасимволы шелла не интерпретируются; исполняться может только `libwarpscout.so` приложения либо chmod).
- Android: файловые операции моста ограничены allow-list корней (папка данных, Download/WARPScoutGUI, /storage/emulated/0/WARPScoutGUI, внутренние каталоги приложения) с санитизацией `getCanonicalPath`; `content://`-URI принимаются только из собственных SAF-диалогов или с persisted grant (follow-up: резолв только через локальный equals-guard); ключи storage валидируются по `[A-Za-z0-9._-]`.
- Windows/Linux/macOS: без изменений функциональности.

## [2.5.3] — 2026-10-11

## [2.5.0] — 2026-10-11

Кроссплатформенный пререлиз: единая кодовая база для шести платформ (развёрнуто — `desktop-app/RELEASE-2.5.0.md`).

- Windows x86_64: изменений функциональности нет — рефакторинг платформенного слоя без смены поведения (доказан построчной сверкой с 2.4.6 и живыми регрессионными прогонами); пакеты переименованы в формат «имя-OS-архитектура», лицензии вынесены в `licenses/`.
- Linux x86_64 / Linux ARM64: новая платформа — платформенный слой (`~/.local/share`, chmod +x вместо Unblock-File), WebKitGTK-зависимости документированы; ядро warpscout ARM64 проверено под эмуляцией (version/register/scan/отчёт).
- macOS arm64 (Apple Silicon) / macOS x64 (Intel): новая платформа — Darwin-слой (`~/Library/Application Support`, подсказки Gatekeeper `xattr -cr`), системный WKWebView без внешних зависимостей.
- Android ARM64: новая платформа — APK с сенсорным UI (вкладки внизу, главная с основными действиями), warpscout упакован как `lib/arm64-v8a/libwarpscout.so`, фиксированный ключ подписи — обновление поверх без потери данных (versionCode 20500).
- Выпуск прошёл сквозной аудит по методике 2.4.6 (исправлены A1–A6 и B1–B5, включая P1 — путь native lib в APK); win-инвариантность против 2.4.6 доказана структурно и живыми прогонами; политика «все платформы в каждом релизе» зафиксирована как постоянная.
