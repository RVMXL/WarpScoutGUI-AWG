Аккаунт WARP

            
Скану нужен аккаунт WARP — это обычная регистрация устройства в Cloudflare, как у официального клиента. Приватный ключ остаётся на вашей машине.

            

              
Файл аккаунта…

              
Путь…

              
WG/AWG-устройство…

              
MASQUE-устройство…

              
Внешнее (WARP-in-WARP)…

            

            

              
              
              
              
              
              
              
              
            

            
Файл кладётся сюда (путь выше). Если warpscout-account.json лежит рядом с warpscout.exe в bin — кнопка «Проверить снова» подхватит его без перезапуска. По умолчанию файл хранится в %APPDATA%\WARPScoutGUI.exe (вместе с отчётами и кэшем движка); папку можно сменить в Настройках → «Папка данных».

            
«Обновить ключи» меняет ключи, не создавая новое устройство. «Новый аккаунт» регистрирует устройство с нуля. Готовый аккаунт из другой установки: «Импорт файла аккаунта» сам проверит JSON (нужны ключи private_key и peer_public_key) и сохранит его в папку выше с нужным именем.

Папка данных

            
Аккаунт, отчёты и веб-кэш движка (EBWebView) — в одной папке: %APPDATA%\WARPScoutGUI.exe. Она создаётся программой сама и всегда на месте — никаких ссылок и объединений. Можно выбрать и другую папку — например, на другом диске.

Данные приложения

            
Настройки, пресеты и последние результаты хранятся локально в хранилище приложения. Резервная копия — один JSON-файл со всеми параметрами, пресетами и историей.

            

              
              
              
              
              
            

          

          

            
О приложении

            

              WARPSCOUT GUI — графическая оболочка для консольной утилиты
              warpscout (v0.16.0, MIT).
              Ищет живые эндпоинты Cloudflare WARP из вашей сети, показывает узел и регион выхода и генерирует готовые конфиги WireGuard / AmneziaWG.


              Дефолтная команда: warpscout scan -p awg -P -n 10 -exclude-node DME


              Скан запускается локально, без серверов-посредников: туннели поднимаются с вашей машины.

⇅ Сравнение сканов

        
      

      

        

          
          ⇄
          
        

        

        
Δ-пинг считается по общим эндпоинтам (A → B: зелёный — стало быстрее, красный — медленнее). Наборы берутся из сохранённой истории.

      

    

  


  
  

    

    

      

        
▣ QR-код конфига

        
      

      

        
        

          
          страница 1 из 2
          
        

        

        
Отсканируйте камерой в AmneziaVPN («Сканировать QR-код») — конфиг перенесётся без файлов. Длинный конфиг разбивается на страницы: сканируйте их по очереди, пока все не соберутся, порядок не важен. В WireGuard длинный конфиг вносится файлом.

        

          
          
        

      

    

  


  
  

    

    

      

        
⚡ Быстрая проверка

        
      

      

        

          
          
        

        

        

        

        
Одна строка warpscout вместо целого скана: -target IP -port PORT — handshake на указанный порт и пинг внутри туннеля. Вердикты сохраняются в журнал проверок (панель 🕘 История).
