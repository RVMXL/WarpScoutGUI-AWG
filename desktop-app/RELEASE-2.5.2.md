# WARPSCOUT GUI v2.5.2 — исправления Android-версии (smoke-тест №2)

[English](RELEASE-2.5.2.en.md) | Русский

Второй пакет исправлений по итогам smoke-теста **на реальном устройстве** (Android). Как и раньше: каждый релиз содержит артефакты **всех шести платформ** под единой версией.

## Android — что исправлено (по пунктам баг-репорта)

1. **Вкладка «Аккаунт» скроллилась влево-вправо** — длинный путь `warpscout-account.json` распирал строку «Путь». Теперь путь переносится, горизонтальный дрейф запрещён на всех 8 вкладках (проверено на 412px: 0 переполнений).
2. **«Сломанная иконка» вкладки** — это десктопный индикатор активного пункта (полоска слева) протекал в нижнюю навигацию. Убран; подписи вкладок, скрытые мобильной media-квери десктопа, возвращены.
3. **Индикатор активной вкладки теперь строго ПОД иконкой** (между иконкой и подписью), плюс штриховые SVG-иконки вместо эмодзи в SVG-тексте (на части устройств «Ещё» не отрисовывалась).
4. **«Открыть папку» работала молча** — приватный каталог `/data/user/0/…` файловые менеджеры не видят. Теперь кнопки открывают **публичную копию** `Download/WARPScoutGUI` через системный файловый менеджер и **всегда** отвечают уведомлением с путём.
5. **Контент прятался за нижними вкладками** — каркас больше не зависит от `100dvh` (не поддерживается старыми WebView): `.main` фиксируется inset'ами, отступ снизу 84px + safe-area.
6. **Главная = панель быстрых действий**: «Просканировать эндпоинты» запускает скан прямо с главной (фаза и число живых эндпоинтов видны там же), «Получить рабочий конфиг» берёт лучший эндпоинт последнего скана, собирает и сохраняет конфиг с кнопками «Открыть папку»/«Скопировать» — без переходов по вкладкам.
7. **Файлы пользователя — в общее хранилище**: отчёты сканов, сохранённые конфиги и копия файла аккаунта автоматически дублируются в `Download/WARPScoutGUI` (Android 10+ — MediaStore, без разрешений; Android 7–9 — Downloads). Служебные данные остаются в приватном каталоге — это нормально.

Плюс: `versionCode` 20502 (обновление поверх 2.5.0/2.5.1 без удаления данных), сертификат подписи не менялся (`67969FF2…AC9841`).
