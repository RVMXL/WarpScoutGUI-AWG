# WARPScoutGUI v2.5.3 — файлы пользователя Android в «своей папке»

[English](RELEASE-2.5.3.en.md) | Русский

Третья партия правок Android-версии по smoke-тестам на реальном устройстве. Пользовательские файлы (аккаунт, отчёты, конфиги) теперь живут в видимой папке на `/storage/emulated/0` без root, а «Открыть папку» открывает строго её и никогда не молчит.

### Изменения по платформам

| Платформа | Статус |
|---|---|
| 🤖 Android (ARM64) | **изменён** — 3 пункта ниже |
| 🪟 Windows x64 | изменений НЕТ — пересобран под единый номер 2.5.3 |
| 🐧 Linux x64 / ARM64 | изменений НЕТ — пересобран под единый номер 2.5.3 |
| 🍎 macOS arm64 / x64 | изменений НЕТ — пересобран под единый номер 2.5.3 |

### Android — детали

- 📁 **Папка данных без root.** По умолчанию: `Android/data/ru.warpscout.gui/files/WARPScoutGUI` (запись всегда, разрешения не нужны). Опционально — общая `/storage/emulated/0/WARPScoutGUI`: Настройки → «🌐 В общую папку…» (Android 11+ — переключатель «Все файлы», Android 7–10 — право на запись; данные переносятся автоматически). Файлы из приватного каталога 2.5.2 переносятся в новую папку при первом запуске 2.5.3. warpscout работает прямо в этой папке — зеркалирование в Downloads больше не нужно.
- 📂 **«Открыть папку» всегда отвечает.** Открывается строго своя папка данных (корень тома и системные каталоги никогда не открываются). Цепочка с ответом в каждой ветке: системный менеджер файлов → SAF-выбор, открытый на нужной папке → путь в буфер обмена + уведомление. Молчаливые отказы исключены.
- 📐 Подсказка «Папка данных» переносит длинные пути (переполнение вкладки настроек на экране 412px устранено).
