 ЧТО ЭТО
 Графическое приложение для macOS, которое ищет живые эндпоинты
 Cloudflare WARP из вашей сети, показывает узел и регион выхода
 и генерирует готовые конфиги WireGuard / AmneziaWG
 (версии 1.5 / 2.0 / 3.1).
 Две сборки: WARPScoutGUI-2.5.1-mac-arm64.zip для Apple Silicon
 (M1/M2/M3/M4 и новее) и WARPScoutGUI-2.5.1-mac-x64.zip для
 Intel-маков. Какая у вас: меню  → «Об этом Mac», или в
 Терминале uname -m (arm64 — Apple Silicon, x86_64 — Intel).
 Статус выпуска: ПРЕРЕЛИЗ 2.6.1 — кроссплатформенный выпуск
 на единой кодовой базе (Windows, Linux x64/arm64, macOS Intel/
 Apple Silicon, Android). Стабильный Windows-релиз:
 WARPScoutGUI-2.4.6-win64.zip. Все исправления аудита v2.4.6
 сохранены. См. ниже раздел «СТАТУС ВЕРИФИКАЦИИ».

 ТРЕБОВАНИЯ
 - macOS 11 Big Sur или новее; mac-arm64 — Mac на чипе Apple
   Silicon, mac-x64 — Mac на процессоре Intel.
 - Дополнительных зависимостей НЕТ: интерфейс работает на
   системном движке WebKit (WKWebView, встроен в macOS), ядро
   warpscout использует только системные библиотеки.
 - Программа НЕ подписана сертификатом Apple Developer, поэтому
   macOS может спросить подтверждение при первом запуске —
   см. «Если macOS блокирует запуск (Gatekeeper)» ниже.

 УСТАНОВКА
 1. Распакуйте архив ЦЕЛИКОМ в любое место (например,
    ~/WARPScoutGUI). Внутри должна остаться структура:
    WARPScoutGUI, resources.neu, bin/warpscout — не разъединяйте их.
 2. Снимите метку «скачано из интернета» (quarantine) — macOS
    ставит её на все файлы из сети и может назвать приложение
    «повреждённым». В Терминале из папки программы:
       xattr -cr .
    (это снимет метку со всех файлов программы сразу).
 3. Выдайте право на запуск (один раз):
       chmod +x WARPScoutGUI bin/warpscout
 4. Запустите из Терминала:
       ./WARPScoutGUI
    Двойной щелчок в Finder тоже работает, но неподписанную
    программу при первом запуске macOS попросит подтвердить —
    см. ниже.

 ЕСЛИ macOS БЛОКИРУЕТ ЗАПУСК (GATEKEEPER)
 - «Не удаётся открыть, так как не удаётся проверить
   разработчика» — обычная ситуация для программ без подписки.
   Варианты:
   а) Терминал: xattr -cr . из папки программы (см. «Установка»,
      шаг 2) — после этого запуск проходит без вопросов;
   б) Системные настройки → «Конфиденциальность и безопасность» →
      внизу кнопка «Всё равно открыть»;
   в) Правый клик по WARPScoutGUI в Finder → «Открыть» →
      «Открыть» в диалоге.
 - Сообщение «приложение повреждено и не может быть открыто»
   почти всегда означает quarantine-метку — помогает шаг (а).

 ОБНОВЛЕНИЕ
 1. Скачайте архив новой версии и распакуйте его.
 2. Скопируйте файлы новой версии поверх старой папки
    (WARPScoutGUI, resources.neu, bin/warpscout), затем снова
    выполните xattr -cr . и chmod +x (метки quarantine и права
    на новых файлах сбрасываются).
 3. Аккаунт, отчёты и настройки переносить не нужно: они хранятся
    в ~/Library/Application Support/WARPScoutGUI и при обновлении
    не теряются.

 ВАЖНО: ПАПКА ДАННЫХ (НЕ УДАЛЯТЬ / НЕ ПЕРЕМЕЩАТЬ)
 - При первом запуске приложение создаёт папку
     ~/Library/Application Support/WARPScoutGUI
   В ней живут аккаунт (warpscout-account.json), отчёты/,
   настройки (.storage).
 - НЕ УДАЛЯЙТЕ и НЕ ПЕРЕМЕЩАЙТЕ эту папку: без неё приложение
   потеряет аккаунт и настройки.
 - Перенести данные в другое место можно штатно:
   Настройки → «Папка данных» → «📁 Выбрать…».

 ПЕРВЫЕ ШАГИ
 1. Вкладка «Аккаунт» → «Зарегистрировать» (создаёт аккаунт WARP,
    ключи остаются на вашей машине).
 2. Вкладка «Скан» → кнопка «Начать скан».
    Дефолтная команда: warpscout scan -p awg -P -n 10 -exclude-node DME
 3. Вкладка «Конфиг» → выберите версию AWG, DNS и эндпоинт из
    результатов скана → «Сохранить как…» → импортируйте конфиг
    в AmneziaVPN / AmneziaWG / WireGuard.

 РЕГИСТРАЦИЯ И АККАУНТ
 - Файл аккаунта: ~/Library/Application
   Support/WARPScoutGUI/warpscout-account.json.
   Кнопка «Открыть папку» на вкладке «Аккаунт» открывает нужную
   папку сама. Папку данных можно сменить: Настройки → «Папка данных».
 - Приложение само создаёт папку данных до регистрации.
 - Готовый аккаунт из другой установки (в том числе с Windows или
   Linux): «📥 Импорт файла аккаунта» — приложение проверит JSON
   (нужны ключи private_key и peer_public_key) и сохранит его в
   нужное место с нужным именем warpscout-account.json.

 ЕСЛИ РЕГИСТРАЦИЯ ПАДАЕТ С «КОДОМ -1»
 На macOS самые частые причины — quarantine-метка Gatekeeper или
 отсутствие права на запуск у bin/warpscout. Порядок действий:
 1. Нажмите «🔓 Разрешить запуск (chmod +x)» на вкладке «Аккаунт» —
    приложение само выполнит chmod +x для найденного файла.
 2. Убедитесь, что quarantine снята: xattr -cr . из папки программы.
 3. «🔎 Проверить warpscout» должен показать: warpscout готов: 0.16.0.
 4. Дополнительная диагностика: в Терминале из папки программы
      ./bin/warpscout version
    Если файл на месте и исполняемый, а код -1 повторяется —
    смотрите Console (Программы → Утилиты → Console).

 КОМАНДНАЯ СТРОКА
 Ядро доступно и напрямую:
   ./bin/warpscout version
   ./bin/warpscout scan -p awg -P -n 10 -exclude-node DME -o report.txt
 GUI вызывает те же команды — «Скопировать команду» на вкладке
 «Скан» даёт готовую строку для Терминала.
