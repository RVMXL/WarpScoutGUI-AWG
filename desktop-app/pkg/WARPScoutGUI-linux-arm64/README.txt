 ЧТО ЭТО
 Графическое приложение для Linux ARM64 (AArch64), которое ищет
 живые эндпоинты Cloudflare WARP из вашей сети, показывает узел
 и регион выхода и генерирует готовые конфиги WireGuard /
 AmneziaWG (версии 1.5 / 2.0 / 3.1).
 Сборка для 64-битных ARM-систем: Raspberry Pi 5 (64-битная ОС),
 ARM-ноутбуки и серверы, Apple Silicon (Mac M1/M2/M3/M4) под
 виртуальной машиной или эмуляцией с Linux ARM64.
 Статус выпуска: ПРЕРЕЛИЗ 2.5.9 — кроссплатформенный выпуск
 на единой кодовой базе (Windows, Linux x64/arm64, macOS Intel/
 Apple Silicon, Android). Стабильный Windows-релиз:
 WARPScoutGUI-2.4.6-win64.zip. Все исправления аудита v2.4.6
 сохранены. См. ниже раздел «СТАТУС ВЕРИФИКАЦИИ».

 ТРЕБОВАНИЯ
 - Linux ARM64 (AArch64) с графической средой (X11 или Wayland).
   32-битный ARM (armhf) не поддерживается этой сборкой.
 - WebKitGTK (движок интерфейса). Обычно уже установлен (GNOME,
   Xfce и т. д.). Если нет — установите пакет:
     Debian/Ubuntu/Raspberry Pi OS:
                     sudo apt install libwebkit2gtk-4.1-0
                     (на старых системах: libwebkit2gtk-4.0-37)
     Fedora:         sudo dnf install webkit2gtk4.1
     Arch:           sudo pacman -S webkit2gtk-4.1
 - Статический warpscout дополнительных библиотек не требует.

 УСТАНОВКА
 1. Распакуйте архив ЦЕЛИКОМ в любое место (например,
    ~/WARPScoutGUI). Внутри должна остаться структура:
    WARPScoutGUI, resources.neu, bin/warpscout — не разъединяйте их.
 2. Выдайте право на запуск (один раз):
       chmod +x WARPScoutGUI bin/warpscout
 3. Запустите:
       ./WARPScoutGUI
    (или двойным щелчком в файловом менеджере — см. «Если файл
    "не запускается" двойным щелчком» ниже).

 ОБНОВЛЕНИЕ
 1. Скачайте архив новой версии и распакуйте его.
 2. Скопируйте файлы новой версии поверх старой папки
    (WARPScoutGUI, resources.neu, bin/warpscout) и снова выполните
    chmod +x, если право на запуск сбросилось.
 3. Аккаунт, отчёты и настройки переносить не нужно: они хранятся
    в ~/.local/share/WARPScoutGUI и при обновлении не теряются.

 ВАЖНО: ПАПКА ДАННЫХ (НЕ УДАЛЯТЬ / НЕ ПЕРЕМЕЩАТЬ)
 - При первом запуске приложение создаёт папку
     ~/.local/share/WARPScoutGUI
   В ней живут аккаунт (warpscout-account.json), отчёты/,
   настройки (.storage).
 - НЕ УДАЛЯЙТЕ и НЕ ПЕРЕМЕЩАЙТЕ эту папку: без неё приложение
   потеряет аккаунт и настройки.
 - Перенести данные в другое место можно штатно:
   Настройки → «Папка данных» → «📁 Выбрать…».

 ПЕРВЫЕ ШАГИ
 1. Вкладка «Аккаунт» → «Зарегистрировать» (создаёт аккаунт WARP,
    ключи остаются на вашей машине).
 2. Вкладка «Скан» → кнопка «Начать скан».
    Дефолтная команда: warpscout scan -p awg -P -n 10 -exclude-node DME
 3. Вкладка «Конфиг» → выберите версию AWG, DNS и эндпоинт из
    результатов скана → «Сохранить как…» → импортируйте конфиг
    в AmneziaVPN / AmneziaWG / WireGuard.

 РЕГИСТРАЦИЯ И АККАУНТ
 - Файл аккаунта: ~/.local/share/WARPScoutGUI/warpscout-account.json.
   Кнопка «Открыть папку» на вкладке «Аккаунт» открывает нужную
   папку сама. Папку данных можно сменить: Настройки → «Папка данных».
 - Приложение само создаёт папку данных до регистрации.
 - Готовый аккаунт из другой установки (в том числе с Windows):
   «📥 Импорт файла аккаунта» — приложение проверит JSON (нужны
   ключи private_key и peer_public_key) и сохранит его в нужное
   место с нужным именем warpscout-account.json.

 ЕСЛИ РЕГИСТРАЦИЯ ПАДАЕТ С «КОДОМ -1»
 На Linux самая частая причина — у файла bin/warpscout нет права
 на запуск (сразу после распаковки архива). Порядок действий:
 1. Нажмите «🔓 Разрешить запуск (chmod +x)» на вкладке «Аккаунт» —
    приложение само выполнит chmod +x для найденного файла.
 2. Либо вручную: chmod +x bin/warpscout (из папки программы).
 3. «🔎 Проверить warpscout» должен показать: warpscout готов: 0.16.0.
 4. Дополнительная диагностика в терминале:
      ./bin/warpscout version
    Если файл на месте и исполняемый, а код -1 повторяется —
    смотрите системный журнал (journalctl) и путь в Настройках.

 ЕСЛИ ФАЙЛ «НЕ ЗАПУСКАЕТСЯ» ДВОЙНЫМ ЩЕЛЧКОМ
 - Проверьте, что выдано право на запуск (chmod +x WARPScoutGUI).
 - Многие файловые менеджеры по умолчанию открывают исполняемые
   файлы в редакторе. Запустите из терминала: ./WARPScoutGUI —
   в терминале же появится точный текст ошибки (например,
   «error while loading shared libraries ... libwebkit2gtk» —
   установите WebKitGTK, см. «Требования»).
 - Проверьте разрядность системы: uname -m должно показывать
   aarch64. Если показывает armv7l — у вас 32-битная система,
   эта сборка (ARM64) на ней не запустится.

 КОМАНДНАЯ СТРОКА
 Ядро доступно и напрямую:
   ./bin/warpscout version
   ./bin/warpscout scan -p awg -P -n 10 -exclude-node DME -o report.txt
 GUI вызывает те же команды — «Скопировать команду» на вкладке
 «Скан» даёт готовую строку для терминала.

 БЕЗОПАСНОСТЬ
 - Ключи аккаунта создаются и хранятся локально; наружу уходят
   только запросы регистрации в Cloudflare.
 - resources.neu подписан манифестом SHA256 (формат бандла
   Neutralino). Не заменяйте файлы поодиночке — обновляйте
   весь архив целиком.
 - warpscout — сторонняя утилита (MIT, github.com/vernette/warpscout).
