 WARPSCOUT GUI v2.0.0
 Графическая оболочка для warpscout v0.16.0 (github.com/vernette/warpscout)
════════════════════════════════════════════════════════════

 ЧТО ЭТО
 Графическое приложение для Windows 10/11, которое ищет живые
 эндпоинты Cloudflare WARP из вашей сети, показывает узел и регион
 выхода и генерирует готовые конфиги WireGuard / AmneziaWG
 (версии 1.5 / 2.0 / 3.1).

 УСТАНОВКА
 1. Распакуйте папку целиком в любое место (например, D:\WARPScoutGUI).
 2. Запустите WARPScoutGUI.exe.
    - Возможно предупреждение SmartScreen: нажмите «Подробнее» →
      «Выполнить в любом случае».
 3. Готово. Установка не требуется.

 ПЕРВЫЕ ШАГИ
 1. Вкладка «Аккаунт» → «Зарегистрировать» (создаёт аккаунт WARP,
    ключи остаются на вашей машине).
 2. Вкладка «Скан» → кнопка «Начать скан».
    Дефолтная команда: warpscout scan -p awg -P -n 10 -exclude-node DME
 3. Вкладка «Конфиг» → выберите версию AWG, DNS и эндпоинт из
    результатов скана → «Сохранить как…» → импортируйте конфиг
    в AmneziaVPN / AmneziaWG / WireGuard.

 ЧТО НОВОГО В 2.0.0
 - ⚡ Журнал проверок: каждый вердикт быстрой проверки (рабочий /
   разорван / не ответил) сохраняется в таймлайн внутри панели
   «🕘 История» — со временем, протоколом, пингом и узлом.
   Экспорт в CSV и очистка — кнопками в шапке журнала.
 - ☑ Пакетная проверка: кнопка «Выбрать» включает режим чекбоксов
   в таблице — отметьте несколько эндпоинтов и запустите очередь
   ⚡-проверок одной кнопкой. Прогресс и итог — в панели и модалке.
 - ⬇ SVG в блоке динамики пинга: график тренда сохраняется в вектор
   (масштабируется без потерь, оформление следует теме).
 - ⬇ HTML-отчёт: кнопка над таблицей сохраняет автономный HTML-файл
   со всей таблицей и статистикой — удобно отправить кому угодно.
 - Примечание модалки ⚡ обновлено: вердикты больше не теряются —
   они попадают в журнал проверок.

 ЧТО НОВОГО В 1.9.0
 - ⚡ Быстрая проверка эндпоинта: пятая кнопка в строке результата
   запускает warpscout scan -target IP -port PORT -P — handshake и
   пинг одного адреса за секунды, без полного скана. Вердикт и
   лог показываются в отдельной модалке.
 - 🚪 Частота портов: в панели статистики появились чипы портов
   рабочих эндпоинтов (🚪 2408 ×3) — клик фильтрует таблицу.
 - ⬇ PNG в блоке динамики пинга: график тренда сохраняется в PNG
   (ретина-качество, оформление следует теме приложения).
 - Подсказки SNI: для -i1-sni и -masque-sni выпадающий список из
   исходников warpscout (i1Hosts + masque default).
 - Тема сайта теперь следует системной настройке, пока не выбрана
   своя (на лендинге).

 ЧТО НОВОГО В 1.8.0
 - «Прямой эфир» во время скана: под кнопкой запуска появляется
   живая панель — таймер, текущая фаза, график прогресса по шагам
   и чипы узлов, появляющиеся прямо из потока warpscout.
 - Шаринг пресетов: кнопки ⬆/⬇ в карточке «Пресеты» — выгрузите
   свои пресеты в JSON-файл и передайте другу; импорт аккуратно
   добавляет новые и сообщает о совпавших по имени.
 - Мелкая полировка: акцентная полоса у строки при наведении,
   приятное нажатие кнопки скана, исправлена опечатка в подсказке
   переключателя темы.

 ЧТО НОВОГО В 1.7.0
 - Сравнение двух сканов (⇅ сравнить в панели истории): выберите
   сканы A и B — приложение покажет, как изменился лучший пинг,
   какие эндпоинты появились/пропали и таблицу Δ-пинга по общим
   эндпоинтам (зелёный — стало быстрее, красный — медленнее).
 - «⬇ CSV» в блоке динамики пинга: выгрузка графика лучшего пинга
   по всем сканам в CSV (дата + пинг) — удобно для отчётов.
 - Переключатель языка RU/EN теперь есть и в справке горячих
   клавиш (кнопка «?»).
 - Строки таблицы результатов появляются каскадом сразу после
   скана — результат видно глазом, а не «морганием».
 - Мелкая полировка: стиль кнопки сравнения, подложки в модалке
   сравнения для светлой темы, аккуратный фокус с клавиатуры.

 ЧТО НОВОГО В 1.6.0
 - Английский язык: переключатель RU / EN в сайдбаре. Переведён весь
   интерфейс (вкладки, таблица, подсказки, уведомления); выбор языка
   запоминается. По умолчанию — русский.
 - Сортировка таблицы кликом по заголовку столбца: эндпоинт, пинг,
   потери, узел, локация. Повторный клик меняет направление. Кнопка
   «↕ пинг» работает как прежде и синхронизирована с заголовком.
 - Кнопка «⬇ CSV (итоги)» в панели истории: сводная таблица всех
   сканов (дата, протокол, параметры, рабочие/разорванные, лучший
   пинг) — удобно для Excel.
 - Полировка: липкая шапка таблицы с размытием при прокрутке,
   мерцание прогресс-бара во время скана, мягкое свечение карточек,
   аккуратные фокус-кольца с клавиатуры.

 ЧТО НОВОГО В 1.5.0
 - Полный импорт .conf (кнопка «📥 Импорт .conf целиком»): подставьте
   готовый конфиг WireGuard / AWG 1.5–3.1 — приложение само определит
   версию и заполнит DNS, MTU, эндпоинт, keepalive, AllowedIPs,
   junk-параметры, H1–H4, I1 и тайминги 3.1. Ключи из файла не
   переносятся — они всегда берутся из аккаунта (это безопаснее).
 - 📉 Динамика лучшего пинга в панели истории: линия по всем сканам,
   клик по точке загружает тот скан в таблицу.
 - Кнопка «⧉ IP» над таблицей: скопировать все рабочие эндпоинты
   списком (по одному в строке).
 - При запуске приложения подсвечивается пресет, соответствующий
   сохранённым параметрам скана.
 - Полировка: акцентные планки в заголовках карточек, микро-анимации
   чипов и строк, полоса-таймер в уведомлениях.

 ЧТО НОВОГО В 1.4.0
 - Свои пресеты скана: кнопка «＋ Свой» сохраняет текущие параметры
   под именем; чипы-пресеты переключаются одним кликом, ✕ удаляет.
 - Δ-сравнение с любым сканом из истории (кнопка Δ) — покажет,
   какие эндпоинты появились и пропали, не загружая скан в таблицу.
 - QR-код конфига (кнопка «▣ QR»): отсканируйте камерой в
   WireGuard / AmneziaVPN — конфиг уедет на телефон без файлов.
   Для длинных AWG-конфигов с большим I1 QR не помещается —
   приложение честно предупредит.
 - Резервная копия и восстановление: все настройки, пресеты и
   история — в один JSON-файл (Настройки → Данные приложения).
 - Компактная плотность таблицы («≡ плотность») и иконки в
   уведомлениях; исправлено: таблица результатов теперь
   восстанавливается при запуске приложения.

 %LOCALAPPDATA%\WARPScoutGUI\
