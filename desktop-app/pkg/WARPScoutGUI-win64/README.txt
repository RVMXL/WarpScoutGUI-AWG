 ЧТО ЭТО
 Графическое приложение для Windows 10/11, которое ищет живые
 эндпоинты Cloudflare WARP из вашей сети, показывает узел и регион
 выхода и генерирует готовые конфиги WireGuard / AmneziaWG
 (версии 1.5 / 2.0 / 3.1).
 Статус выпуска: ПРЕРЕЛИЗ 2.6.2 — кроссплатформенный выпуск
 на единой кодовой базе (Windows, Linux x64/arm64, macOS Intel/
 Apple Silicon, Android); функциональность 2.4.6 сохранена.
 Windows-логика не менялась — см. ниже «СТАТУС ВЕРИФИКАЦИИ».

 УСТАНОВКА
 1. Распакуйте папку целиком в любое место (например, D:\WARPScoutGUI).
 2. Запустите WARPScoutGUI.exe.
    - Возможно предупреждение SmartScreen: нажмите «Подробнее» →
      «Выполнить в любом случае».
 3. Готово. Установка не требуется.

 ОБНОВЛЕНИЕ
 1. Скачайте ZIP новой версии и распакуйте его.
 2. Скопируйте файлы новой версии поверх старой папки (или распакуйте
    в новую папку — старую после этого можно удалить).
 3. Аккаунт, отчёты и настройки переносить не нужно: они хранятся
    в %APPDATA%\WARPScoutGUI.exe (AppData\Roaming), а не в папке
    программы, и при обновлении не теряются.

 ВАЖНО: ПАПКА ДАННЫХ В APPDATA (НЕ УДАЛЯТЬ / НЕ ПЕРЕМЕЩАТЬ)
 - При первом запуске приложение СОЗДАЁТ папку
   %APPDATA%\WARPScoutGUI.exe (это AppData\Roaming). В ней живут
   аккаунт (warpscout-account.json), отчёты\, настройки (.storage)
   и веб-кэш движка EBWebView.
 - НЕ УДАЛЯЙТЕ и НЕ ПЕРЕМЕЩАЙТЕ эту папку: без неё приложение
   потеряет аккаунт и настройки, а переименование собьёт пути.
 - Перенести данные в другое место можно штатно:
   Настройки → «Папка данных» → «📁 Выбрать…».

 ПЕРВЫЕ ШАГИ
 1. Вкладка «Аккаунт» → «Зарегистрировать» (создаёт аккаунт WARP,
    ключи остаются на вашей машине).
 2. Вкладка «Скан» → кнопка «Начать скан».
    Дефолтная команда: warpscout scan -p awg -P -n 10 -exclude-node DME
 3. Вкладка «Конфиг» → выберите версию AWG, DNS и эндпоинт из
    результатов скана → «Сохранить как…» → импортируйте конфиг
    в AmneziaVPN / AmneziaWG / WireGuard.

 РЕГИСТРАЦИЯ И АККАУНТ (важно, v2.1.0)
 - Файл аккаунта: %APPDATA%\WARPScoutGUI.exe\warpscout-account.json
   (это AppData\Roaming, а НЕ AppData\Local; папка называется
   «WARPScoutGUI.exe» — так устроен рантайм, в ней же лежат отчёты
   и веб-кэш движка). Кнопка «Открыть папку» на вкладке «Аккаунт»
   открывает нужную папку сама. Папку данных можно сменить:
   Настройки → «Папка данных».
 - Приложение само создаёт папку данных до регистрации — раньше
   папки не было, и аккаунт не сохранялся даже после успешной
   регистрации (ошибка «код 1»).
 - Готовый аккаунт из другой установки: нажмите «📥 Импорт файла
   аккаунта» и выберите файл — приложение проверит JSON (нужны
   ключи private_key и peer_public_key) и сохранит его в нужное
   место с нужным именем warpscout-account.json. Вручную кладите
   файл по пути выше и следите, чтобы Блокнот не добавил «.txt»
   к имени, затем нажмите «🔄 Проверить снова» — перезапуск
   приложения НЕ нужен.
 - Автоподхват: если warpscout-account.json лежит рядом с
   warpscout.exe (в bin\), рядом с WARPScoutGUI.exe или в
   %APPDATA% — приложение само подключит его (при запуске или по
   кнопке «Проверить снова»).
 - «Код -1» в логе регистрации означает, что warpscout.exe не
   смог запуститься или был закрыт: чаще всего это антивирус
   (добавьте папку в исключения) или неполная распаковка ZIP
   (рядом с WARPScoutGUI.exe должна лежать папка bin).
 - Если в логе «Cloudflare API недоступна»: регистрация требует
   доступа к api.cloudflareclient.com — попробуйте VPN/прокси
   или повторите позже.

 ЧТО НОВОГО В 2.4.6
 - 🔒 СЕРИЯ ИСПРАВЛЕНИЙ БЕЗОПАСНОСТИ И НАДЁЖНОСТИ по результатам
   независимого аудита (56 пунктов; закрыты все критичные):
 • Импортируемые данные (backup, пресеты, история) больше не могут
   изменить shell-команду: строгие enum'ы протокола/генератора I1
   проверяются на границе построения команды; каждое значение —
   строго один аргумент (пробелы/символы cmd вырезаются).
 • Эндпоинты из чужой истории парсятся строго (host:port, IPv6
   без скобок, порт 1..65535) — shell-синтаксис не проходит.
 • HTML-инъекция в истории сканов закрыта (счётчики — только числа).
 • «Разблокировать exe» корректно экранирует апострофы в пути.
 • Импорт backup больше НЕ восстанавливает путь к warpscout.exe
   (переносимые настройки не влияют на выбор исполняемого файла).
 • Ключи аккаунта проверяются как настоящие ключи WireGuard
   (32 байта base64) — инъекция директив в .conf невозможна;
   неоднозначный public_key отклоняется, алиас нормализуется
   в файле (CLI видел его иначе, чем GUI).
 • Экспорт конфига/QR/копия — только с загруженным аккаунтом
   (раньше сохранялся шаблон-заглушка без ключей).
 • Смена папки данных переписана: сравнение путей без учёта
   регистра/разделителей, запрет вложенных папок, файлы удаляются
   только ПОСЛЕ проверки записи, конфликты не перезаписываются,
   при ошибке активная папка не меняется. Потеря данных при
   переносе в ту же папку («C:\Warp» → «c:\warp») исключена.
 • Импорт аккаунта сохраняет резервную копию прежнего файла.
 • Гонки скана устранены: у запуска есть сессия-id, Stop работает
   даже если процесс ещё не появился, финализация старого скана
   не затирает новый, отчёты получают уникальные имена.
 • Пакетная проверка ⚡ больше не зависает на ошибке одной
   строки, «Отмена» реально останавливает очередь и процесс.
 • .conf-импорт — ЗАМЕНА профиля: старые Table/keepalive/I1/DNS
   не протекают в новый конфиг; несколько [Peer] — берётся первый
   с предупреждением; I2–I5 (AWG 2.0) больше не теряются;
   неизвестные директивы перечисляются явно.
 • Конфиг-экспорт соблюдает лимиты CLI (Jc 1–128, Jmin≤Jmax,
   Jmax≤1280) — CLI больше не отклоняет сохранённые профили.
 • find-junk/find-sni понимают реальный вывод CLI 0.16.0
   («warpscout.exe … -proto …»); «Применить к скану» строит
   ЧИСТЫЙ профиль (старые фильтры/генераторы не искажают смысл).
 • QR: PNG сохраняется тем же уровнем коррекции, что и превью
   (конфиги 2332–2953 байт больше не «показываются, но не
   сохраняются»); не-ASCII символы кодируются UTF-8.
 • SOCKS: адрес показывается после реального запуска и гаснет
   при остановке; порт и эндпоинт валидируются.
 • Ошибки хранения честнее: сообщение при ненулевом коде выхода
   скана, flush записи после смены папки/сброса, лимиты буферов
   логов и живого графика.
 - ♿ Доступность: модалки перехватывают фокус (фон inert, хоткеи
   под диалогом отключены, фокус возвращается на кнопку), сортировка
   таблицы и Δ-сравнение доступны с клавиатуры, сегменты — настоящие
   радиогруппы (стрелки/aria-checked), кнопки строк видны при Tab,
   контраст вторичного текста поднят до WCAG AA в обеих темах,
   у иконок навигации появились aria-label.
 - 🧹 Журнал ⚡-проверок рендерится даже при пустой истории сканов;
   сброс честно перечисляет, что чистит; тема/компактный режим
   переведены через переводчик (EN больше не ломался); fallback
   копирования честно сообщает неудачу.

   колонка TUN PING — все столбцы после PING съезжали на один влево:
   в LOSS показывался TUN PING (ms), в SEEN AS — потери (%),
   в NODE — страна, а «Локация узла» показывала код узла вместо

   SEEN AS — страна (флаг + код), NODE — код узла, ЛОКАЦИЯ УЗЛА —
   город и страна (как в выводе warpscout).
 - ↕ Колонка TUN PING теперь сортируемая (клик по заголовку);
   сортировка PING сортирует по ICMP-пингу эндпоинта.
