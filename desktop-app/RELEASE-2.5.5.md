# WARPScoutGUI v2.5.5 — примечания к релизу

[English](RELEASE-2.5.5.en.md) | Русский

**Дата / Date:** 2026-10-11 · **Тип:** prerelease · **Ядро / core:** warpscout v0.16.0

Единый выпуск для всех шести платформ (политика выпуска: артефакты всех платформ под одним номером версии).

### Android (изменён)

- **🛡 Закрыты все 19 предупреждений CodeQL (GitHub code scanning).** Релиз содержит только защитные улучшения оболочки — поведение пользователя не меняется:
  - **Запуск команд без шелла.** Раньше команда из GUI исполнялась через `sh -c` — код сканирования помечал это как возможную инъекцию команд. Теперь команда разбирается POSIX-совместимым токенизатором (кавычки `'`/`"`, `\`-экранирование — как у sh) и запускается напрямую через `ProcessBuilder` в виде argv: метасимволы шелла (`; & | \` $()`) никогда не интерпретируются, а исполняемым файлом может быть **только** собственное ядро `libwarpscout.so` (или `chmod` для выдачи права на запуск). Всё прочее — честная ошибка вместо запуска.
  - **Файловые операции — только в своих папках.** Чтение/запись/создание/удаление/листинг через JS-мост ограничены разрешёнными корнями: своя папка данных (`…/WARPScoutGUI`), публичная папка конфигов (`Download/WARPScoutGUI`), общая папка (`/storage/emulated/0/WARPScoutGUI`), внутренние каталоги приложения. Пути канонизируются (`getCanonicalPath` — «..»-обходы и симлинки нейтрализуются); всё прочее отклоняется с явной ошибкой, которую интерфейс показывает пользователю.
  - **content:// URI — только свои.** Операции с URI принимаются лишь для файлов, выбранных в СОБСТВЕННЫХ диалогах приложения (или с сохранённым правом доступа) — произвольные URI из JS не открываются.
  - **Ключи хранилища валидируются** (`[A-Za-z0-9._-]`, без «..») — файл настроек не может выйти из внутреннего каталога.
- Установкa поверх 2.5.0–2.5.4: тот же пакет, тот же ключ подписи (сертификат SHA-256 `67969ff2…ac9841`), данные сохраняются.

### Windows / Linux / macOS (изменений нет)

По политике выпуска пакеты пересобраны под единый номер 2.5.5 (`resources.neu`, `README.txt`); функциональных изменений нет.

### Обновление

- **Android:** ставится поверх 2.5.0–2.5.4 (тот же ключ подписи). Данные сохраняются.
- **Desktop:** распаковать zip поверх старой папки; аккаунт/отчёты/настройки не затрагиваются.
