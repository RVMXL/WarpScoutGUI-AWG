# Политика безопасности

## Как сообщить об уязвимости

Пожалуйста, **не создавайте публичный issue** для сообщений об уязвимостях.

Используйте приватный канал GitHub: вкладка **Security → Report a vulnerability**
в этом репозитории — сообщение увидит только владелец.

Ответ — в течение нескольких дней; при подтверждении — исправление
в ближайшем релизе.

## Область применения (scope)

Наиболее чувствительные зоны приложения:

- обработка конфигурационных файлов: импорт `.conf`, парсинг параметров
  AmneziaWG/WireGuard (включая QR-экспорт формата AmneziaVPN — приложение
  показывает и сохраняет QR, но не сканирует чужие QR-коды);
- формирование командной строки и запуск `warpscout.exe`;
- хранение аккаунта WARP на диске
  (`%APPDATA%\WARPScoutGUI.exe\warpscout-account.json`).

## Не является уязвимостью

- **Предупреждения SmartScreen / антивирусов.** Приложение не подписано
  сертификатом кода — для portable-утилиты это ожидаемое поведение Windows,
  а не уязвимость (см. README.txt в архиве).
- **Скан эндпоинтов WARP с вашего IP** — это и есть заявленная функция
  приложения, унаследованная от warpscout CLI.
- Приложение работает полностью локально: нет телеметрии и серверной части.
  Слушаются только локальные адреса: внутренний порт Neutralino для обмена
  UI ↔ ядро и опциональный SOCKS5-прокси на 127.0.0.1 (порт задаёте вы,
  по умолчанию 1080) — слушается только пока прокси запущен.
